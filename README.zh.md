# UI 自动化测试工具

基于 Midscene Studio 的桌面自动化测试工具，支持网页和安卓测试。网页操作由 Playwright 执行，视觉断言与补充操作交给 Agent。

**[下载 Windows x64 安装包（v1.14.1）](https://github.com/JayZhu03/midscene/releases/download/v1.14.1/midscene-studio-beta-v1.14.1-win32-x64-setup.exe)** · [版本说明](https://github.com/JayZhu03/midscene/releases/latest)

## 功能

- **录制与编辑**：录制操作、查看步骤截图，添加自然语言操作和断言。
- **场景执行**：管理多个脚本及执行顺序，支持单独执行、连续执行和手动继续，操作失败时由 Agent 尝试接管。
- **测试报告**：查看和下载 HTML 报告，包含操作流程、截图证据及异常记录。
- **导入导出**：通过 ZIP 包分享脚本或整个场景。

## 安装与升级

支持 Windows 10 / 11（64 位）。运行安装包，选择安装目录，完成后从桌面或开始菜单打开。

旧版升级：先退出 Studio，再安装到原目录，保留模型配置、网页、场景和脚本。

## 使用

1. **配置模型**：填写服务地址、API Key、模型名称和模型系列，选择支持图像输入的模型。参数说明见[模型配置文档](https://midscenejs.com/zh/model-common-config.html)。
2. **添加网页或连接安卓设备**：网页尺寸默认 `1920 × 1080`，可自行调整；安卓需安装 ADB、开启 USB 调试并授权电脑，也支持无线 ADB。
3. **新建场景并录制**：点击「录制新脚本」，完成操作，按需添加断言，例如「页面提示保存成功」。
4. **保存并执行**：停止录制后查看、修改和保存脚本，执行单条脚本或整个场景，结束后点击「查看报告」。

## 录制注意事项

1. **悬浮菜单先点击，再选择。** 例如左侧导航栏，先点击导航图标，再选择二级菜单；仅靠鼠标悬停展开的过程可能漏录。
2. **切换输入框时优先点击，不要用 `Tab` 代替。** 例如登录时，输入用户名后，先点击密码框再输入密码。

## 数据与协作

- 场景和脚本保存在本机，通过导出 ZIP 包备份或分享；导入重名内容会创建副本。
- 执行记录只保留最近 **10 次**，重要报告请及时下载。
- 导出包保留录制输入（包括测试密码）、网址和截图，不包含模型配置及登录会话；换电脑后需重新配置模型、登录并准备测试数据。

## 源码运行

需要 Node.js `^20.19.0 || ^22.12.0 || >=24.0.0`、pnpm `>=9.3.0`。

```powershell
corepack enable
pnpm install
pnpm --filter studio dev
```

构建与开发说明见 [CONTRIBUTING.md](./CONTRIBUTING.md)。
