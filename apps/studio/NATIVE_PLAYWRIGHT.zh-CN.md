# 原生 Playwright 导出

在 Studio 的 Web 浏览器中开始录制，手动完成操作并结束录制。在录制详情的“代码”中选择“原生 Playwright”，或在回放列表的脚本三个点菜单中选择“导出 Playwright”，保存 `.spec.ts`。

编译和导出不调用模型。脚本只依赖 `@playwright/test`（本版以 1.58.1 验证），回放时不使用 Midscene，也不消耗模型 token。录制界面原有的 AI 描述、Markdown 生成功能仍是独立功能，可能调用模型。

## 运行

在测试目录安装 Playwright，并把导出的文件放到该目录：

```powershell
corepack pnpm add -D @playwright/test@1.58.1
corepack pnpm exec playwright install chromium
# 有密码步骤时，按脚本顶部列出的变量名设置实际输入值。
$env:MIDSCENE_INPUT_006 = '实际密码'
corepack pnpm exec playwright test ./录制名称-playwright-native.spec.ts
```

密码值不会写入导出的代码；每个密码输入步骤使用独立环境变量。追加输入、清空、替换和光标选区分别保留。脚本包含定位唯一性检查和已观察到的跳转等待；请补充订单状态、查询结果等业务断言。

## 定位和限制

录制在每次手动操作执行前采集 DOM，优先使用测试属性、语义属性、文本及组件范围。Ant Design Select 的清空按钮和展开箭头分别记录，选择值覆盖输入框时记录可点击的选择框。拖拽同时保存起终点元素及元素内相对位置。

定位会排除隐藏副本，并通过表单标签、卡片／弹窗标题和表格行键区分同名控件。行定位不依赖行号，可应对排序变化。同一字段内多个输入或组件子控件会使用唯一业务范围内的相对结构路径；这类路径在组件内部结构调整后可能需要重新录制。查询按钮优先匹配独立文案，避免角标数量变化影响定位。

语义定位不足时，自动使用 Playwright 1.58.1 的定位器生成器补充，并校验生成结果与实际操作元素一致，无需修改业务前端或手填定位器。生成器仅按需加载，不开启 Playwright 录制浮层或重复执行操作。

同名且无可区分业务信息的控件可以使用结构／序号定位；脚本会注明此策略，并在 `nth` 定位前核验候选数量。数量变化会中止测试，但相同数量的同名控件换序仍可能影响目标，应重新录制。定位不足时仍明确报错，不跳过步骤或把导出成功当作测试通过。

当前支持点击、双击、右键、长按、input/textarea 和 contenteditable 输入及选区、按键、明确距离或四个方向到边缘的滚动、基于 DOM 起终点的拖拽、开放 Shadow DOM、页面跳转及视口尺寸。滚动按方向选择实际容器，处理嵌套容器到边缘后的滚动传递。复杂自定义拖拽、无限加载列表仍需实际页面验证。Canvas、iframe、封闭 Shadow DOM 尚未支持。

旧 Markdown ZIP 及仅有截图、AI 操作描述的脚本没有录制时 DOM 数据，不能直接编译；这次增强对升级后新录制的数据生效。工具生成的是操作脚本，业务断言仍需按用例补充。18 步本地复杂控件场景已完成三次全新上下文回放，不代表 MOM 达到 99% 成功率。
